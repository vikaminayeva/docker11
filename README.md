Контейнеризация сервиса посылок на Go через Docker 🐳

Финальный учебный проект, посвященный упаковке, конфигурации и развертыванию приложения (сервиса отслеживания посылок с базой данных SQLite) в изолированной среде с помощью **Docker**. Проект демонстрирует навыки создания легковесных production-ready Docker-образов для Go-приложений.

##  Описание проекта
В рамках задания был разработан и настроен файл `Dockerfile`, собирающий одноконтейнерное приложение. Образ включает в себя компиляцию исходного кода на Go, подключение необходимых CGO-зависимостей для корректной работы встроенной СУБД SQLite (`tracker.db`) и подготовку окружения для стабильного запуска.

### Реализованные шаги автоматизации сборки:
*   Выбор оптимальных базовых Docker-образов для экосистемы Go.
*   Настройка рабочей директории и копирование исходного кода проекта.
*   Управление зависимостями и компиляция бинарного файла приложения.
*   Конфигурация контейнера для работы с персистентными данными (файлом базы данных SQLite).

---

## Оптимизация Dockerfile (Multi-stage Build)
Для минимизации размера итогового Docker-образа и повышения безопасности в проекте применен подход **многоэтапной сборки**:
1.  **Stage 1 (Сборщик):** На базе полноценного образа `golang` происходит загрузка зависимостей и компиляция исполняемого файла приложения.
2.  **Stage 2 (Финал):** Минималистичный и безопасный образ (например, `alpine` или `distroless`), в который копируется *только* скомпилированный бинарник и файл базы данных. Это позволяет сократить размер образа в несколько раз и убрать лишний исходный код из production-среды.

##  Инструкция по сборке и запуску контейнера

### 1. Сборка Docker-образа
Для сборки образа с вашим уникальным Docker ID и тегом версии выполните команду в корне проекта:
```bash
docker build -t ВАШ_DOCKER_ID/go-parcel-tracker:v1 .
```

### 2. Запуск контейнера
Запустите изолированный контейнер из созданного образа:
```bash
docker run --name parcel-service-container -d ВАШ_DOCKER_ID/go-parcel-tracker:v1
```

### 3. Проверка работы
Чтобы убедиться, что приложение внутри контейнера успешно запустилось и работает с базой данных, проверьте логи:
```bash
docker logs parcel-service-container
```
